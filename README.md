## What is this project

This project aims to build a simple social media platform in which you can post content and write comments on those posts
General features of this app are :
  - Sign up or sign in with email or google account
  - Creating posts
  - Liking posts
  - Writing comments
  - Replying to comments
  - Searching 
  - ...


## Tech Stack
- Framework: Next js App router
- Data Access: Prisma with postgresql
- Backend: Route handlers + Server actions
- Client API : Axios + Tanstack Query
- Testing: Vitest + React Testing Library

## Getting Started


Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
